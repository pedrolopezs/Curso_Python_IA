# Programación Python con Integración de IA

Repositorio del curso. Contiene los ficheros de apoyo de los laboratorios,
organizados por tema.

## Estructura

Cada tema tiene su propio directorio con esta organización.

- `src/`: scripts de Python para ejecutar desde la terminal o desde VS Code.
- `notebooks/`: los mismos ejercicios en formato notebook de Jupyter.
- `data/`: ficheros de datos, cuando el tema los necesita.

## Entorno de trabajo

Los laboratorios están preparados para la máquina virtual del curso
(Xubuntu 26.04 LTS con Python 3.14, VS Code y Git).

El repositorio se descarga en el directorio `~/Curso_Python` de la máquina
virtual y el entorno virtual `.venv` se crea en su raíz.

```
git clone URL_DEL_REPOSITORIO Curso_Python
cd Curso_Python
```

A medida que avanza el curso se incorporan nuevos temas. Para traerlos
basta con ejecutar `git pull` dentro del repositorio.
