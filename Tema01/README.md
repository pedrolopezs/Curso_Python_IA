# Tema 1. Entorno de desarrollo

Ficheros de apoyo del laboratorio del Tema 1.

## Contenido

| Fichero | Descripción |
|---|---|
| `src/holamundo.py` | Comprueba el entorno Python en uso |
| `src/sangria_y_tipado.py` | Ejemplos de sangría y tipado |
| `notebooks/01_entorno_desarrollo.ipynb` | Mismos ejemplos en un notebook |

## Ejecución

Desde la raíz del repositorio y con el entorno virtual activado.

```
python Tema01/src/holamundo.py
python Tema01/src/sangria_y_tipado.py
```

Los notebooks se abren en VS Code y se ejecutan con el kernel del
entorno virtual `.venv`.
